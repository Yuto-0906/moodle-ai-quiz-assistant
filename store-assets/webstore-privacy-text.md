# Chrome Web Store 入力文面

## 単一用途の説明

Moodle AI Quiz Assistant は、Moodle の小テスト画面で問題文・選択肢・画像を読み取り、ユーザーが選択した ChatGPT または Gemini に送信して回答候補を取得し、学習・教材検証を支援することだけを目的とした拡張機能です。

## storage 権限を要求する理由

AI プロバイダーの選択、API キー、利用モデルなど、ユーザーが拡張機能のポップアップで設定した内容をブラウザ内に保存するために使用します。保存した設定は、次回以降も同じ設定で利用できるようにする目的でのみ使います。

## tabs 権限について

現在の manifest では `tabs` 権限を削除済みです。ChatGPT Web や Gemini Web のタブの作成・削除に使用する `chrome.tabs.create()`、`chrome.tabs.remove()`、`chrome.tabs.onRemoved` は Manifest V3 では `tabs` 権限なしで利用可能なため、この権限は不要です。

## ホスト権限を要求する理由

Moodle の小テストページでは、問題文、選択肢、入力欄、問題内画像を読み取り、回答候補をフォームに反映するために `http://*/mod/quiz/*` と `https://*/mod/quiz/*` へのアクセスが必要です。OpenAI API と Google Gemini API へのアクセスは、ユーザーが API モードを選択した場合に回答候補を取得するために使用します。ChatGPT と Gemini の Web サイトへのアクセスは、ユーザーが Web UI モードを選択した場合に、ログイン済みの AI 画面へプロンプトを送信し、回答テキストを取得するために使用します。

## activeTab 権限について

現在の manifest では `activeTab` 権限を削除済みです。この権限は現在の実装では使用していないため、Chrome Web Store の入力欄で理由を記載する必要はありません。

## リモートコードの使用について

この拡張機能はリモートコードを使用しません。拡張機能内で実行される JavaScript はすべてパッケージに含まれており、外部サーバーから取得した JavaScript を実行しません。OpenAI、Gemini、ChatGPT Web、Gemini Web から取得する内容は回答テキストであり、コードとして実行せず、JSON またはテキストとして解析して Moodle のフォーム入力に利用します。

## データ使用の表明

この拡張機能は、ユーザーが実行した場合にのみ Moodle 小テストページの問題文、選択肢、入力欄情報、問題内画像を処理します。これらのデータは、ユーザーが選択した AI サービスに回答候補を生成させる目的でのみ送信されます。拡張機能の開発者が独自のサーバーでデータを収集、保存、販売、第三者提供することはありません。保存されるデータは、AI プロバイダー、API キー、モデルなどの設定情報に限られ、Chrome のローカルストレージに保存されます。

## データ使用が Google のデベロッパー プログラム ポリシーに準拠していることの表明

本拡張機能は、取得したデータを単一用途である Moodle 小テストの学習・教材検証支援のためにのみ使用します。ユーザーデータを販売せず、用途外の広告配信、信用評価、第三者への転送には使用しません。取り扱うデータは機能提供に必要な範囲に限定し、Google の Chrome Web Store デベロッパー プログラム ポリシーに準拠して使用します。

## ストア掲載用の詳細説明

Moodle AI Quiz Assistant は、Moodle の小テスト画面で ChatGPT や Gemini を活用した解答支援を行う Chrome 拡張機能です。インストールすると、Moodle のテスト受験ページに「AIで解答」ボタンが表示され、問題文・選択肢・画像などを読み取って、選択した AI に回答候補を生成させることができます。OpenAI API、Google Gemini API、ChatGPT Web、Gemini Web に対応しており、API キーを使う方法とログイン済みの Web UI を使う方法を用途に応じて切り替えられます。選択式、記述式、数値入力、穴埋め、並べ替え、マッチングなど複数の Moodle 問題形式に対応しているため、自己学習、教材作成後の確認、小テストの動作検証を効率化できます。手作業で問題をコピーして AI に入力する手間を減らし、回答候補の取得からフォームへの反映までをスムーズに行える点が大きなメリットです。本拡張機能は、自己学習、教材検証、または所属機関や管理者から許可された用途で使用してください。問題文や画像は選択した AI サービスに送信される場合があるため、利用前に所属機関の規則、Moodle サイトの利用条件、各 AI サービスの利用規約を確認してください。
